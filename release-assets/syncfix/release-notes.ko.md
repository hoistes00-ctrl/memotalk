# 메모톡 동기화 수정판 다운로드

Windows 설치 파일과 Android 수정판 APK를 아래 Assets에서 받으세요.

- **Windows:** `MemoTalk-Setup-17.1.1-sharing.5-syncfix.1-x64.exe`
- **Android:** `MemoTalk-Android-17.1.1-sharing.5-syncfix.2.apk` — 앱 이름 **메모톡 동기화 수정판**, 패키지 `kr.memotalk.app.sharingpreview5.syncfix`, 버전 코드 25.
- `SHA256SUMS.txt`는 파일 확인용 체크섬이며 `build-info.json`에 소스와 빌드 출처가 기록돼 있습니다.

## 수정 내용

다른 공유 그룹의 원본을 보존하면서 반복 읽기를 줄이고, 현재 처리 단계와 네이티브 요청 진단을 표시합니다. 빠른 파일 읽기를 사용하며, Android에서 아직 없는 상위 폴더를 읽을 때 EIO로 중단되던 문제를 고쳤습니다. 실제 양방향 병합은 `operations/*.json`을 사용하고 `readable/*.md`는 읽기용 출력입니다.

## 설치와 기존 데이터

기존 앱과 메모를 삭제하거나 초기화하지 마세요. 먼저 별도 백업을 보관하고 확인하세요. 기존 공유 그룹을 새로 만들 필요가 없습니다.

Android APK는 실제 휴대폰에 설치·재시작·왕복 검증한 파일과 바이트 단위로 같습니다. 이미 **메모톡 동기화 수정판** 버전 코드 25를 사용 중이면 다시 설치할 필요가 없습니다. 이 수정판의 향후 덮어 업데이트에는 같은 서명이 필요합니다. 예전 공유 시험판과는 앱 ID와 서명이 달라 별도 앱으로 설치되며, 기존 데이터와 폴더 권한이 자동 이전되지는 않습니다. 새 앱에서는 같은 공유 폴더를 직접 선택해야 합니다. 백업 가져오기는 중복 메모를 추가할 수 있으므로 원본을 보존하고 결과를 확인하세요.

Windows 설치 파일은 같은 소스 커밋에서 GitHub Actions가 새로 빌드하고 실제 설치형 앱의 수신·송신 시험까지 통과한 결과입니다. 이전 로컬 설치 파일과 해시는 다를 수 있습니다. Windows 실행본들은 같은 사용자 프로필을 쓸 수 있으므로 기존 실행본을 종료한 뒤 사용하세요. Windows EXE에는 전자서명이 없습니다.
