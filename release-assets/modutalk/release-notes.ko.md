# 모두톡 17.3.0 — 같은 공유 방 통합

Android와 Windows에서 같은 공유 방의 복사본을 자동 통합합니다.

- 방 제목·방 생성 시각·공통 메모 작성 시각을 함께 확인합니다. 이름만 같은 다른 방이나 빈 방은 합치지 않습니다.
- 겹치는 메모는 하나로 보이며, 추가 메모·댓글·사진과 서로 다른 편집 내용은 같은 방 안에 보존합니다.
- 통합 관계를 공유 이력에 남겨 오프라인에서 늦게 도착한 메모도 같은 방으로 모읍니다. 원래 JSON과 읽기용 파일은 삭제하지 않습니다.
- 통합을 만들거나 받기 전에 안전 백업을 저장합니다. 작성 중 문장과 첨부 대기 사진도 유지합니다.
- 앱 ID·서명·Windows 저장 위치를 유지합니다. 기존 앱을 삭제하지 말고 그 위에 업데이트하세요.

기본 검사 82개, 두 앱 화면에서 반복 백업 가져오기, 원본·댓글·사진·편집본·입력 중 자료 보존, Android SAF/WebView와 Windows 설치본의 왕복 통합을 검증합니다. sourceRunUrl 및 검증 결과는 build-info.json에서 확인할 수 있습니다. 실제 Galaxy Flip5에 17.3.0을 설치한 결과는 아직 확인하지 못했습니다. 이전 17.2.0의 설치 확인과 구별합니다.

날짜를 알 수 없는 옛 복사본이나 생성 시각이 다른 방은 자동 통합하지 않을 수 있습니다. 서로 다른 편집 문장을 추측하여 다시 쓰지 않고 각각 보존합니다. 개인정보·사용자 백업·비밀 키는 공개 파일에 포함하지 않습니다.
