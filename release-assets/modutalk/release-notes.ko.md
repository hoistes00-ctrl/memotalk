# 모두톡 17.2.0

Windows와 Android의 앱 이름과 버전을 모두톡 17.2.0으로 통일했습니다. 기존 동기화 수정 내용을 포함합니다.

- Windows: 설치 파일 또는 포터블 파일을 사용하세요. 기존 메모와 공유 폴더 설정을 이어서 사용합니다.
- Android: 기존 동기화 수정판 위에 APK를 설치하세요. 앱 ID와 서명을 유지하여 데이터를 보존합니다. 앱을 삭제한 뒤 설치하지 마세요.
- 원래의 다른 서명 앱은 자동 삭제하지 않습니다.
- 공개된 APK는 기존 휴대폰과 같은 서명으로 만든 파일입니다. 이번 버전의 실제 Galaxy Flip5 업데이트는 USB 연결이 어려워 아직 확인하지 못했습니다.

기본 검사 64개와 GitHub의 PC–Android 왕복 검증 결과는 연결된 소스 실행 기록에서 확인할 수 있습니다. Windows 이전 버전에서 새 버전으로 방·메모·댓글·연결 설정을 유지하는 별도 시험도 통과했습니다.

개인 메모, 사용자 백업 및 비밀 서명 키는 업로드하지 않았습니다. SHA256SUMS.txt와 build-info.json에서 각 파일의 출처와 해시를 확인할 수 있습니다.
