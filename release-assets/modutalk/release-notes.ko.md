# 모두톡 17.5.0 — 한 화면 자동 동기화

휴대폰에서 모두톡 메모 화면과 Obsidian Sync를 같은 앱에서 실행합니다. 모두톡 아이콘으로 이 화면을 열 수 있으며, 두 앱을 번갈아 열거나 동시에 띄워 둘 필요가 없습니다. Obsidian Sync의 기존 구독과 볼트 연결은 계속 사용합니다.

## 설치

1. 기존 모두톡 수정판 위에 Android APK를 설치합니다. 기존 앱을 삭제하지 마세요.
2. `Modutalk-Obsidian-17.5.0.zip`을 풀고 `modutalk-sync-view`를 휴대폰 볼트의 `.obsidian/plugins/`에 넣습니다.
3. Obsidian 커뮤니티 플러그인에서 **모두톡 동기화 화면**을 활성화하고 **모두톡 열기** 명령을 실행합니다.
4. **공유 폴더 선택**에서 기존 공유 그룹이 있는 폴더를 고릅니다. 내용이 자동으로 나타납니다. 백업 불러오기나 그룹 재생성은 필요하지 않습니다.
5. 기존 모두톡의 **파일 저장 → 모두톡 한 화면 자동 동기화**에서 볼트 이름을 입력하면 아이콘의 시작 화면을 바꿀 수 있습니다. 미전송 기록과 작성 중인 내용을 먼저 저장하세요.

APK만 설치하면 Obsidian 플러그인이 자동으로 설치되지는 않습니다. Windows는 설치형 또는 무설치형을 계속 사용합니다. 기존 앱 데이터는 보존됩니다. 아이콘을 길게 누른 뒤 **기존 메모 보기**로 돌아가 시작 화면 설정을 되돌릴 수 있습니다.

## 실제 검증

- Galaxy Flip5에 동일 앱 ID·기존 서명으로 17.5.0을 덮어 설치했습니다.
- 기존 앱을 종료한 뒤 모두톡 아이콘을 다시 실행해 Obsidian 안의 모두톡 화면 하나가 열리는 것을 확인했습니다.
- 한 화면에서 PC 수정의 자동 수신과 휴대폰 수정의 PC 도착을 각각 약 4.5초·4.2초에 확인했습니다. 양쪽 JSON 바이트 해시가 같았습니다. 속도 보장은 아닙니다.
- 화면을 닫았다 다시 열었을 때 텍스트 초안이 복구됐습니다.
- 원래 공유 파일 1,528개는 삭제·내용 변경 없이 보존됐습니다. 기존 메모 135개와 댓글 61개도 새 화면에서 확인했습니다. 기존 앱의 업데이트 직전 메모 내용도 보존됐습니다.
- 최신 진단에서 처리 완료 시각이 있고 현재 오류 없음, 보낼 기록 0개, 기다리는 부모 기록 0개를 확인했습니다. 과거 충돌과 다른 그룹 원본은 보존합니다.
- 자동 검사 101개와 별도 Android 검사, Windows·Android 브라우저 및 설치형 왕복 검사를 수행합니다. 전체 CI 성공 후에만 이 릴리스를 공개합니다.

화면을 끄거나 앱을 닫은 동안의 즉시 전송까지 보장하지는 않습니다. 원격 파일 도착은 Obsidian Sync가 담당합니다. `operations/*.json`은 변경 기록, `readable/*.md`는 읽기용 출력입니다. 보내지 않은 사진·수정 중인 글은 화면을 닫기 전에 저장하세요.

설치 파일, 플러그인, 빌드 정보와 체크섬을 함께 제공합니다. 개인 메모·백업·서명 키는 업로드하지 않습니다.
