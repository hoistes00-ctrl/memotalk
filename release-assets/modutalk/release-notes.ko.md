# 모두톡 17.4.0

PC 목록에서 제목이 잘려 읽기 어려운 문제를 고치고, 현재 앱 폴더와 실제 저장 폴더를 함께 확인할 수 있게 했습니다.

- 방·폴더 이름 전체 표시를 기본으로 적용. 2줄·1줄 요약도 선택 가능하며 마우스를 올리면 전체 제목을 확인합니다.
- 제목 크기·줄 간격을 즉시 조절하고 저장하거나 기본값으로 복귀할 수 있습니다.
- 방 상단의 위치 표시 또는 파일 저장 메뉴에서 앱 내 경로, 연결된 저장 위치, 경로 복사를 제공합니다. PC에서는 탐색기로 열 수 있습니다.
- 목록에서 찾기를 누르면 접힌 상위 폴더를 펼쳐 현재 방을 찾습니다. 입력 중인 글은 유지합니다.
- Android는 제공자가 알려준 폴더 경로와 문서 ID를 표시합니다. 알 수 없는 실제 경로를 만들어 표시하지 않습니다.

Windows·Linux에서 86개 자동 검사, PC·Android 화면 폭의 제목·위치 검사, 양쪽에서 시작하는 공유 왕복 검사를 통과했습니다. Android SAF/WebView 실행 검사 및 Windows 설치형 검사 결과는 연결된 원본 검증 실행에서 확인할 수 있습니다.

기존 모두톡 수정판 위에 설치해 사용하세요. Android 앱 ID와 기존 서명은 유지했습니다. 원래 앱이나 메모를 삭제할 필요가 없습니다. Galaxy Flip5에서 이번 17.4.0을 직접 설치한 확인은 아직 완료하지 않았습니다.
