# 모두톡 17.4.1

휴대폰에서 같은 공유 폴더에 참여해도 첫 메모 반영까지 오래 기다리는 문제를 줄이는 수정입니다. 백업을 먼저 불러오는 것은 필수가 아닙니다.

- Android가 JSON마다 수백 개 파일 목록을 다시 조회하던 작업을 줄였습니다. 문서 주소만 한 처리 주기 동안 재사용하며 파일 내용은 매번 읽고 검증합니다.
- 새로운 파일은 목록을 다시 조회하고 사라진 주소는 재조회합니다. 주기 변경이나 앱의 파일 변경 때 목록을 초기화합니다. 쓰기 검증에는 캐시를 쓰지 않습니다.
- 검증한 기록을 32개마다 로컬 중간 저장해, 앱 종료 후에도 이미 받은 기록을 건너뛰고 이어 읽습니다. 전체 확인 전에는 기존 메모를 바꾸지 않습니다.
- 첫 처리 중 현재 기록 번호를 표시합니다. 과거처럼 연결됨 표시만 남아 있는 상태를 줄입니다.
- 17.4.0의 제목 전체 표시와 앱·저장 폴더 위치 보기는 유지합니다.

Windows·Linux 자동 검사 88개, 첫 수신 중단 후 재개·저장 실패 시 원본 보존 검사, 600개 문서 주소 조회·최신 내용·늦은 파일 검사 및 Android SAF/WebView·Windows 설치형 공유 회귀 검사를 검증 실행에서 확인할 수 있습니다.

기존 모두톡 수정판 위에 설치합니다. Android 앱 ID·서명을 유지했습니다. 기존 앱 삭제·백업 재불러오기·공유 그룹 재생성은 필요하지 않습니다. 실제 Galaxy Flip5의 이번 수정판 첫 처리 주기 완료는 아직 확인 전입니다. 원래 진단의 약 45분은 경과 시간이며 백그라운드 시간을 포함할 수 있어 전부 파일 읽기 시간으로 단정하지 않습니다.
