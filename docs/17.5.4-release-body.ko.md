# 모두톡 연동 화면 17.5.4

- 방의 메뉴 → **메모방·백업에서 합치기**에서 현재 방 또는 **파일 저장의 백업·복원에 저장된 백업**을 선택할 수 있습니다. 백업 안의 방을 고르면 차이가 자동으로 비교됩니다. **필요한 메모 합치기**와 마지막 확인을 선택해야 실제로 반영됩니다.
- 백업 목록의 **메모방에 합치기**에서도 같은 기능을 엽니다. 전체 복원과 구분합니다. 기존 방·백업·메모는 보존하고 새 메모만 추가합니다. 댓글·사진·작성일을 유지하고 반복 통합의 중복을 방지합니다. 통합용 안전 백업 생성 시 기존 백업을 정리하지 않습니다.
- 목록의 폴더에 이름 변경 버튼을 바로 표시합니다. 폴더 메뉴의 **폴더 이름 바꾸기**에서도 변경할 수 있습니다. 앱 안의 폴더 이름만 바꾸며 연결된 실제 공유 폴더 경로는 유지합니다.
- 진단 제목이 실제 플러그인 버전을 표시합니다. Windows·Android 독립 앱은 기존 17.5.0 설치 버전을 유지합니다.
- 업데이트의 이전 파일을 고유한 폴더에 보관하고 백업과 복원을 해시로 확인합니다. 복원 실패를 성공처럼 안내하지 않습니다. 작성 중인 글·사진과 미전송 기록이 있으면 먼저 저장하도록 안내합니다. 같은 업데이트를 적용 전 반복 다운로드하지 않습니다.
- Obsidian의 모두톡 플러그인 설정에서 자동 업데이트 확인 간격과 안내 표시 시간을 조절·초기화할 수 있습니다. 안내 시간은 현재 표시 중인 안내에도 적용되고 조절값은 기기에 저장됩니다.

이번 파일은 Obsidian 연동 플러그인 업데이트입니다. 기존 업데이트 기능이 있는 17.5.3에서는 화면 위 **업데이트 → 업그레이드**로 설치한 뒤 플러그인을 껐다 켭니다. 그 이전 버전은 ZIP 안의 네 코드 파일을 기존 플러그인에 적용합니다. 기존 `data.json`, 메모 저장소와 공유 그룹을 초기화하지 마세요.

자동 검사와 실제 Galaxy Flip5 검증을 통과한 시험판입니다. 아래에 실제 확인 범위를 기록했습니다. 화면 꺼짐·앱 종료 동안의 즉시 전송을 보장하지 않습니다.

## 실제 휴대폰 검증 — 2026-11-21

- Galaxy Flip5의 설치된 17.5.3 화면에서 업데이트 → 업그레이드를 눌러 17.5.4로 적용했습니다. 실제 다운로드한 코드 네 파일은 공개 자산의 SHA-256과 일치하고 이전 코드 백업도 일치했습니다.
- 일반 방 통합, 파일 저장의 백업 목록에서 같은 방의 과거 메모 합치기, 자동 비교, 마지막 확인을 실제 화면에서 검증했습니다. 수정된 현재 문장과 백업의 이전 문장을 함께 보존했고 사진·댓글·작성일도 유지했습니다. 같은 백업의 반복 통합은 추가 0개였습니다.
- 폴더의 이름 변경 버튼을 실제 터치해 이름만 바뀌고 방의 소속이 유지되는지 확인했습니다. 폴더 메뉴의 이름 변경, 메모·방 날짜 정렬, 원래 정렬 설정 복귀도 확인했습니다.
- 휴대폰에서 생성한 변경 기록 세 개가 PC에 같은 바이트로 도착했습니다. PC에서 별도 검증 기록을 추가했을 때 휴대폰 메모 목록에 자동으로 반영됐고 파일도 일치했습니다. 연결 변경·전체 복원 없이 진행했습니다.
- 기능 시험 직전 메모 135개의 문장·사진·댓글·작성일, 기존 안전 백업 4개, 기존 공유 파일 2,077개를 대조해 보존을 확인했습니다. 업데이트 직후에는 이전 151개 메모 내용이 그대로였으며 이후 기능 시험 전에 별도의 삭제 기록이 들어왔습니다. 그 기록을 임의로 취소하지 않았으며 업데이트 전 백업을 보관했습니다.
- 단위 검사 58개와 가상 화면의 통합·동기화·제목 검사를 통과했습니다. 최종 전송 대기 수는 0입니다.

### 확인 범위
실제 PC 앱 화면의 반영, 화면 꺼짐·앱 종료 상태의 즉시 전송, 실제 휴대폰의 업데이트 실패 시 복원은 이번 실기기 검사에서 검증하지 않았습니다. 키보드가 나타날 때의 화면 높이 변화는 측정하지 못했습니다. 복원 실패 처리는 자동 검사로 검증했습니다. 시험용 메모와 폴더에는 [검증] 표시를 붙였고 원본 데이터는 초기화하지 않았습니다.
