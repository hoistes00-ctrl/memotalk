# 모두톡 17.4.0

현재 Windows·Android 배포는 **모두톡 17.4.0**으로 이름과 표시 버전을 통일합니다. 이름과 버전의 원본은 루트 `app-info.json`입니다. `python scripts/sync-app-info.py`로 Windows 패키지와 공용/Android 화면 사본을 맞추고 `--check`로 누락을 검사합니다. Android Gradle도 같은 정보를 읽습니다.

## 현재 업데이트 대상

- Windows: 제품 이름·실행 파일·바탕화면/시작 메뉴 바로가기는 모두톡입니다. 내부 앱 ID `kr.memotalk.desktop`과 저장 프로필 `memotalk-desktop`, 기존 파일 연결은 유지합니다.
- Android: 표시 이름은 모두톡, 버전은 17.4.0, 버전 코드는 28입니다. 현재 사용 중인 수정판의 `kr.memotalk.app.sharingpreview5.syncfix` 패키지와 기존 서명을 유지합니다. 내부 ID에 예전 이름이 남아 있는 것은 데이터를 이어받기 위한 의도적인 호환성입니다.
- 다른 내부 빌드 변형도 표시 이름과 버전은 같은 값을 사용합니다. 신규 사용자에게는 현재 통합 APK 하나를 안내합니다. 개발용 별도 앱 ID의 데이터를 자동으로 합치지는 않습니다.

## 기존 데이터와 구형 앱

화면 이름 변경은 메모 ID·공유 그룹·변경 이력 형식을 바꾸지 않습니다. 사용자 메모 안의 과거 앱 이름도 자동으로 고치지 않습니다. 구형 앱이나 원본·백업을 자동 삭제하지 않습니다. 옛 앱에만 남은 최신 데이터는 대조해야 하므로 앱을 지워서 업데이트하지 마세요.

같은 서명의 현재 수정판에는 덮어 업데이트할 수 있습니다. 예전 CI 임시 서명 시험판이나 `kr.memotalk.app` 정식 앱은 다른 설치본일 수 있으므로 그 위에 덮어 설치된다고 보장하지 않습니다. 표시 이름을 바꾸기 위해 앱 ID나 서명을 다시 만들지 않습니다.

## 확인 기준

양쪽 설치 정보와 앱 화면의 이름·버전이 일치하고, Windows 업데이트가 기존 프로필을 사용해야 합니다. 패키지 사본과 공용 UI가 같아야 하며 기존 공유/충돌 보존 검사도 통과해야 합니다. Android 설치 파일의 버전·앱 이름·패키지·인증서는 APK에서 직접 검사합니다. 연결되지 않은 실제 기기 적용은 패키지 검사만으로 완료했다고 표시하지 않습니다.

## 중복 배포 경로 중지

이전의 태그 자동 배포, Windows 다운로드 브랜치 배포, 별도 Android 정식 패키지 배포, Obsidian 시험판 배포 작업은 중지했습니다. 수동으로 실행해도 통합 다운로드 주소만 안내하며 새 파일이나 별도 앱을 만들지 않습니다. 과거에 공개된 파일은 이력으로 보존합니다. 검사용 빌드는 공개 배포를 하지 않습니다.
