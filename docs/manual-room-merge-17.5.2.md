# 모두톡 17.5.2 — 복구 방 내용 합치기·날짜별 정렬 (가상 검증)

이 업데이트는 Obsidian 연동 플러그인의 메모 화면에 추가한 **원본 보존형 수동 통합**과 **화면 전용 날짜 정렬**입니다. 기존 Windows/Android 17.5.0 APK/EXE, 앱 ID 및 서명 정보를 변경하지 않습니다.

## 수동 메모방 통합 사용법
1. 내용을 받을 **기존 메모방**을 엽니다.
2. 채팅방 메뉴(⋮) → **다른 메모방 내용 합치기 · 원본 보존**을 선택합니다.
3. 원본으로 사용할 **복구 방** 또는 다른 방을 선택하고 **내용 비교**를 누릅니다.
4. 원본·대상 메모 수, 새로 가져올 메모 수, 완전 일치 항목, 이전에 가져온 항목을 확인합니다.
5. **통합하기** → 최종 확인을 거치면 백업을 만든 뒤 새 메모를 한 번에 복사합니다.

### 데이터 보호 정책
- 원본 방, 기존 메모, 개별 댓글·사진 및 작성시각은 삭제·덮어쓰기 하지 않습니다.
- 중복 판정은 전체 메모 내용·시간·사진·댓글이 같을 때만 수행합니다. 같은 본문이라도 댓글이나 사진이 다르면 다른 버전으로 보존합니다.
- 같은 원본 방의 의도적인 반복 항목 수를 보존합니다. 이미 가져온 항목은 결정적인 원본·내용 해시로 재실행 시 중복 생성하지 않습니다.
- 같은 메모가 나중에 편집되면 **새 편집본**을 별도 항목으로 추가하고 이전 통합본을 보존합니다.
- 모든 통합은 실제 저장 전에 다시 원본·대상 메모 목록이 바뀌지 않았는지 검사합니다. 다른 변경이 끼어들면 통합을 중단합니다.
- 로컬 백업 생성에 실패하면 통합을 중단합니다. **백업 성공 → 하나의 로컬 저장 작업으로 가져오기** 순서입니다.
- 원본 방을 자동으로 지우거나 숨기지 않으며, 실제 정리가 필요할 때 사용자가 나중에 별도로 결정합니다.
- 수동 통합은 현재 **로컬 저장 백엔드**에서만 제공됩니다. 동일 그룹을 공유하는 PC/휴대폰 간 동기화는 기존 operations 기록을 그대로 사용합니다.

## 날짜별 정렬
- 방 목록의 **⇅** 버튼: 기존 직접 배치, 방 생성일 오래된/최신순, 최근 활동 오래된/최신순.
- 방 내부의 **⇅** 버튼: 메모 작성일 오래된/최신순, 최종 수정일 오래된/최신순.
- 정렬 상태는 기기별 로컬 화면 설정에만 저장합니다. 메모의 실제 시간값이나 동기화 작업 기록을 변경하지 않습니다.
- 날짜가 없거나 유효하지 않은 항목은 마지막에 표시하고, 시간 같은 항목은 안정적인 ID 순서로 정렬합니다.

## 가상 검증
- Node.js 기능 테스트: 반복 통합, 의도적 반복 메모 수, 서로 다른 편집본, 댓글·사진, 원본/날짜 보존, 잘못된 입력 거절, 정렬 불변성.
- 기존 Obsidian 호스트, 공유방 자동 중복 병합, UI 상태 테스트를 다시 실행.
- Playwright Chromium: PC·Android 모사 양방향 동기화 및 방 제목·위치 시험.
- Android Emulator API 35: 네이티브 WebView·SAF 테스트 (에뮬레이터에서 Obsidian 상용 앱 자체의 동작까지 재현하는 검사는 아님).
- 각 검증이 성공한 경우에만 `Modutalk-Obsidian-17.5.2-virtual.N.zip` 테스트 릴리스를 게시하도록 GitHub Actions 구성.

## 기존 버전 안내
이 기능은 Obsidian 연동 화면에 대한 플러그인 테스트 버전이므로 기존 17.5.0 Android/Windows 설치 파일을 제거하거나 그룹을 새로 생성하지 않습니다. 테스트 ZIP은 `.obsidian/plugins/modutalk-sync-view`의 파일만 교체합니다. 실기기 UI/동작은 테스트 릴리스와 분리해서 기록해야 합니다.
