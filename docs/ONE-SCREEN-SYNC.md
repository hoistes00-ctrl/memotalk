# 모두톡 한 화면 자동 동기화 — 17.5.0

휴대폰에서 메모 화면과 Obsidian Sync를 같은 앱 안에서 실행합니다. 두 앱을 번갈아 열거나 함께 띄워 두지 않아도 됩니다. Obsidian Sync 구독과 같은 볼트 연결은 계속 필요합니다. 앱을 닫거나 휴대폰 화면을 끈 동안의 즉시 전송까지 보장하지는 않습니다.

## 설치와 연결

1. 릴리스의 `Modutalk-Obsidian-17.5.0.zip`을 풀고 `modutalk-sync-view` 폴더를 휴대폰 볼트의 `.obsidian/plugins/`에 넣습니다. 기존 앱을 삭제하지 마세요.
2. Obsidian 설정의 커뮤니티 플러그인에서 **모두톡 동기화 화면**을 켭니다.
3. Obsidian 명령 팔레트에서 **모두톡 열기**를 실행합니다. **공유 폴더 선택**에서 PC와 공유하는 기존 그룹 파일이 있는 폴더를 고릅니다. 새 그룹을 만들지 않습니다.
4. 기존 메모가 나타나는지 확인합니다. 새 화면은 같은 `operations/*.json` 기록을 자동으로 읽습니다. 백업 불러오기는 필요하지 않습니다.
5. 기존 모두톡 앱의 **파일 저장 → 모두톡 한 화면 자동 동기화**에서 Obsidian 볼트 이름을 입력해 시작 화면을 바꿀 수 있습니다. 기존 앱의 보낼 기록과 작성 중인 메모를 먼저 저장하세요.

설정 후 모두톡 아이콘은 `obsidian://modutalk?vault=볼트이름`으로 같은 화면을 엽니다. 기존 메모는 기존 앱에 그대로 남습니다. 아이콘을 길게 눌러 **기존 메모 보기**를 선택하면 원래 화면에 돌아갈 수 있습니다. 그 화면에서 **기존 앱 화면으로 시작**을 선택해 되돌릴 수 있습니다.

## 저장과 동작

- 메모 데이터와 설정은 공유 그룹별로 구분한 저장 공간에 보관합니다. Obsidian이나 다른 플러그인의 저장 키와 데이터베이스를 초기화하지 않습니다.
- 기존 그룹을 검증한 뒤 연결합니다. 경로는 선택한 볼트 하위 폴더로 제한합니다.
- 파일을 임시 이름으로 쓰고 내용을 확인한 뒤 Obsidian의 파일 이름 변경 기능으로 게시합니다. 기존 파일과 충돌하면 거부합니다. 사용자 파일을 삭제하거나 덮어쓰지 않습니다.
- `operations/*.json`이 기기 간 변경 기록이며 `readable/*.md`는 읽기용 출력입니다. Markdown 직접 편집을 모두톡에 가져오는 기능과는 구분됩니다.
- 처음에는 공유 기록을 읽는 시간이 필요합니다. 완료 시점과 남은 기록은 **공유 오류 진단**에서 새로 고쳐 확인할 수 있습니다. 주기 완료만으로 원격 도착을 보장하지 않습니다.
- 텍스트 초안은 화면을 다시 열어도 복구합니다. 보내지 않은 사진이나 수정 중인 글은 화면을 닫기 전에 저장하세요.

## 확인 범위

실제 Galaxy Flip5에서 한 화면을 유지한 채 PC 메모 자동 수신과 휴대폰 회신의 PC 도착을 확인했습니다. 첫 시험에서 각각 약 4.2초와 2.5초였습니다. 이 수치는 보장 속도가 아닙니다. 기존 메모 135개와 댓글 61개의 내용도 새 화면에서 모두 확인했습니다. 네트워크·화면 꺼짐·OS 절전 동작은 전송 시간을 늘릴 수 있습니다.
