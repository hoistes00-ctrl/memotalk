# 모두톡 Windows 17.5.5

휴대폰의 Obsidian 플러그인 업데이트만으로는 Windows 앱이 바뀌지 않았습니다. 이번 릴리스는 Windows 설치 앱과 무설치 앱에 17.5.5 화면을 반영합니다.

- 새 메모방·새 폴더·선택·조작 설정·최상위 이동을 한 도구 모음으로 정리했습니다.
- 파일 저장의 백업 목록에서 필요한 방만 통합하고, 차이를 자동 비교하며, 폴더 이름을 변경할 수 있습니다. 메모·사진·댓글·작성일과 원본 백업은 보존합니다.
- Windows가 실제 설치 버전 17.5.5를 인식하게 했습니다. 공유 화면의 Android 버전 표시 때문에 같은 Windows 업데이트를 반복 안내하지 않습니다.
- 기존 앱 ID와 메모 저장소 `memotalk-desktop`을 유지합니다. 현재 앱에서 작성 중인 내용을 저장하고 종료한 뒤 설치 파일로 업데이트하세요. 기존 앱 제거·메모 초기화·공유 폴더 재연결은 필요 없습니다.

`Modutalk-Setup-17.5.5-x64.exe`는 설치형, `Modutalk-Portable-17.5.5-x64.exe`는 무설치형입니다. SHA256SUMS.txt로 파일을 확인할 수 있습니다. 이번 릴리스에는 Android APK가 없습니다. Android 독립 앱은 기존 17.5.0, 휴대폰 Obsidian 플러그인은 17.5.5를 유지합니다.

단위 검사 59개, 실제 포장된 Windows 앱의 메뉴 배치·버전·메모·댓글·연결 설정의 재실행 보존 검사 후 공개합니다. 각 기기별 공개 파일을 구분해 안내하도록 다운로드 페이지 소스도 수정했습니다. 해당 페이지가 실제 배포되기 전에도 이 릴리스의 설치 파일을 직접 받을 수 있습니다.
