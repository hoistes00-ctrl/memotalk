# 메모톡 Windows Obsidian 연동 시험판

Windows Markdown 저장 실패 진단과 안전 복구를 포함한 별도 시험판입니다. main, 기존 v17.0.2 Release 및 기존 다운로드 파일은 교체하지 않습니다. Android APK는 이번 게시에 포함하지 않습니다.

- MemoTalk-Setup-…exe: Windows 64비트 설치형.
- MemoTalk-Portable-…exe: 설치하지 않고 실행하는 Windows 64비트 포터블.
- SHA256SUMS.txt: 두 실행 파일의 SHA-256.
- build-info.json: 빌드한 소스 커밋과 버전.

## Obsidian으로 저장하기

1. 기존 메모톡에서 JSON 백업을 별도로 저장한 뒤 기존 앱을 종료하세요. 포터블도 기존 메모톡 내부 저장소를 사용할 수 있으므로 두 버전을 동시에 실행하지 마세요.
2. 시험판을 실행하고 **파일 저장 → 실제 저장 폴더 연결**을 선택하세요.
3. vault 안에 새 빈 전용 폴더(예: 13.memotalk-preview)를 만들어 선택하세요. 기존 13.memotalk 불완전 저장본은 그대로 보관하세요.
4. **로컬 파일 읽기 검증 완료**가 표시되는지 확인하고 Obsidian에서 Markdown을 여세요.
5. 다른 기기로 보내려면 각 기기의 Obsidian Sync에서 해당 폴더가 제외되지 않았는지 확인하고 **Sync all other types**를 켜 JSON 저장본 정보도 동기화하세요. 로컬 저장 성공은 원격 전송 완료가 아닙니다.

## 포함한 수정

- 실패 파일·네이티브 오류 코드·errno·syscall·쓰기 단계 진단.
- Windows 0바이트 선생성 제거, 임시 쓰기/읽기 검증, 변경 전 이력 사본.
- 작업 기록에 따른 중단 후 재시도와 인덱스 최종 검증.
- 인덱스 없는 이전 불완전 저장본의 읽기 전용 비교 및 새 빈 폴더 복구. 원본 폴더는 수정·삭제하지 않습니다.
- 여러 창의 동시 저장 방지, 폴더 변경 후 오래된 핸들 차단.
- 일반 파일 memotalk-sync-state.json에 SHA-256 저장본 정보 기록. 점으로 시작하는 로컬 인덱스/이력은 Obsidian Sync로 전달되지 않습니다.
- 자동 저장 간격 실시간 조절·리셋·설정 유지.

## 검증과 남은 제약

Windows 자동 테스트 27개(실제 파일 잠금 포함), UI 소스 검사, 설치형/포터블 빌드, 패키지 내 소스 일치 및 다운로드 산출물 체크섬을 확인한 뒤 게시합니다. 코드 서명은 없어 Windows SmartScreen 경고가 표시될 수 있습니다.

실사용 vault의 과거 최초 실패 원인은 로그 부재로 아직 미확정입니다. 실제 두 기기 Sync 전송·설치 후 사용자 데이터 유지·Android 실기기 동작을 완료했다고 주장하지 않습니다. 현 단계는 메모톡 → Obsidian 단방향 저장이며, Obsidian에서 고친 내용을 메모톡으로 자동 가져오지 않습니다. 외부 수정은 덮어쓰지 않고 중단하며, 동시 외부 편집의 경합은 완전히 제거되지 않았습니다.

문제가 있으면 **파일 저장 → 마지막 저장 오류 진단**의 코드·작업·상대 경로를 확인하세요. 진단에는 개인 경로가 포함될 수 있으므로 공개 이슈에 그대로 붙이지 마세요.
