# 모두톡 연동 화면 17.5.5 · 상단 여백과 목록 도구 정리

- 휴대폰 전체 화면에서 Obsidian 머리글을 숨긴 뒤 남아 있던 여백을 없앱니다. 상태 표시줄·카메라의 안전 여백은 유지합니다. Obsidian 메뉴를 다시 열면 원래 여백으로 돌아갑니다.
- 새 메모방·새 폴더·선택·조작 설정·최상위 이동을 한 도구 모음에 배치합니다. 만들기는 앞쪽에, 선택·관리 도구는 뒤쪽에 두고 색과 구분선으로 나눕니다.
- 항상 보이던 끌기 안내 문장은 조작 설정에서 볼 수 있습니다. 화면 읽기 프로그램용 도움말은 유지합니다. 선택했을 때만 필요한 이동·삭제 도구가 추가로 나타납니다.
- 버튼의 터치 높이를 유지하면서 목록 공간을 넓힙니다. 메모·백업·연결 정보는 초기화하지 않습니다.

Obsidian 연동 플러그인 업데이트입니다. 화면 위 업데이트 → 업그레이드로 설치한 뒤 플러그인을 껐다 켜면 적용됩니다. Android·Windows 독립 앱의 설치 버전은 기존 17.5.0을 유지합니다. 공유 기록 정리나 원본 파일 삭제를 수행하는 업데이트가 아닙니다.

자동 검사와 320·360·430px 가상 화면의 버튼 배치, 방·백업 통합 검사를 통과한 뒤 공개합니다. 공개 직후 실제 휴대폰 적용 결과는 별도 작업 보고서에 기록합니다. 화면 꺼짐 상태의 동기화는 이번 변경의 검증 범위가 아닙니다.
