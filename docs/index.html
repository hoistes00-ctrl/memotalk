Android 시험판 주의: 이 APK는 GitHub Actions가 생성한 임시 디버그 서명 파일입니다. 기존에 설치된 메모톡과 서명이 달라 덮어 설치가 안 될 수 있고, 이후 시험판도 같은 서명으로 업데이트된다는 보장이 없습니다. 기존 앱을 삭제하지 말고 메모를 JSON으로 백업하세요.

Windows 설치 주의: 이 설치 파일은 서명되지 않은 시험판이므로 Windows SmartScreen 또는 브라우저에서 경고가 표시될 수 있습니다. 신뢰할 수 있는 출처인지 확인하고 설치하세요. 기존 메모톡 사용자는 먼저 JSON으로 백업해 주세요.

설치 전 기존 메모를 JSON으로 백업하세요. 정식 APK가 기존 디버그 APK와 서명이 다르면 덮어 설치가 불가능합니다. 릴리스가 아직 없으면 다운로드 링크가 열리지 않을 수 있습니다.
