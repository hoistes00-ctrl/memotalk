Android 시험판 주의: 새 시험용 APK는 기존 메모톡과 충돌하지 않도록 ‘메모톡 테스트’라는 별도 앱으로 설치됩니다. 기존 앱과 데이터가 자동 공유되지 않으므로, 내용을 옮기려면 기존 앱에서 JSON 백업 후 시험판에서 가져오세요. 기존 앱은 삭제하지 마세요. 시험판은 임시 디버그 서명으로 향후 자동 업데이트가 보장되지 않습니다.

Windows v17.0.1 설치 주의: 목록에서 메모방을 마우스로 끌어 순서를 저장할 수 있습니다. 설치 파일은 코드 서명이 없는 시험판이므로 Windows SmartScreen 또는 브라우저에서 경고가 표시될 수 있습니다. 신뢰할 수 있는 출처인지 확인하고 설치하세요. 기존 메모톡 사용자는 먼저 JSON으로 백업해 주세요.

설치 전 기존 메모를 JSON으로 백업하세요. 정식 APK가 기존 디버그 APK와 서명이 다르면 덮어 설치가 불가능합니다. 릴리스가 아직 없으면 다운로드 링크가 열리지 않을 수 있습니다.
