# 모두톡 앱 안에서 업그레이드 선택 (Obsidian 플러그인 17.5.3 테스트)

## 화면 동작
- Obsidian의 모두톡 연동 화면을 열면, 연결되어 있을 때 하루가 아니라 **6시간 간격**으로 새 플러그인 릴리스를 확인합니다.
- 새로운 검증된 버전이 있으면 **지금 업그레이드 / 나중에** 중 선택할 수 있습니다. 나중에 선택한 버전은 반복 안내하지 않으며, 더 새 릴리스가 나오면 다시 안내합니다.
- 항상 보이는 상단 **업데이트** 버튼으로 다시 직접 확인할 수 있습니다.
- Windows·Android 단독 앱의 **더보기 → 버전 확인 · 업그레이드**는 정식 설치 파일의 새 버전을 확인하고 다운로드 링크를 제공합니다. OS 승인 없이 APK 또는 EXE를 자동으로 실행/설치하지 않습니다. 이 앱 UI 코드는 향후 재서명된 공식 Android/Windows 실행 파일에 함께 배포되어야 하며, 기존 17.5.0 앱에 소급 적용되는 것은 아닙니다.

## Obsidian 플러그인 업그레이드 안전성
- GitHub 공식 저장소의 버전이 증가한 테스트 릴리스만 표시합니다. 검증 필수 파일: `main.js`, `app.html`, `styles.css`, `manifest.json`.
- 다운로드 URL은 공식 GitHub 릴리스 주소로 제한하고, GitHub 릴리스 메타데이터의 **SHA-256 해시 및 바이트 크기**를 각각 확인합니다.
- 네 파일 모두 검증되고 manifest의 ID·버전이 일치해야 앱 파일을 변경합니다.
- 덮어쓰기 전에 플러그인 디렉터리 내 `.modutalk-backup-이전버전/`에 기존 네 파일을 별도 보존합니다. 쓰기 중 실패하면 기존 파일을 다시 기록합니다.
- **메모 본문, 공유 폴더, 그룹 설정, operations, readable 파일은 수정하지 않습니다.**
- 완료 후 **Obsidian 설정 → 커뮤니티 플러그인 → 모두톡 플러그인 끄기/켜기**로 새 코드를 적용합니다. 전송 중 끊길 수 있으므로 Obsidian Sync의 전송을 먼저 종료하는 편이 안전합니다.
- 네트워크 오류 시 편집 화면을 계속 사용하며, 확인 실패는 사용자가 수동 확인을 요청한 경우에만 보여줍니다.

## 초기 설치와 미래 릴리스
- **중요:** 17.5.2까지에는 인앱 업데이트 선택 코드가 없으므로, 새 기능을 처음 사용하려면 17.5.3 테스트 ZIP을 한 번 수동 설치해야 합니다. 이후 더 새로운 버전부터는 연동 화면 상단에서 업그레이드할 수 있습니다.
- 미래 릴리스 자동 설치를 위해 GitHub Releases에 네 파일이 ZIP과 **별도의 개별 원본 파일**로 올라와야 하며 각 GitHub asset에 `digest: sha256:...`가 있어야 합니다. 업로드가 누락되거나 해시가 없으면 앱 내 자동 업그레이드를 제안하지 않습니다.
- 17.5.3은 가상 브라우저·Node 검증용 테스트 릴리스입니다. 실제 Galaxy Flip5의 Obsidian 재시작/메뉴 레이아웃 검증은 별도로 필요합니다.

## 검증
- `node --test tests/in-app-updates.test.cjs`: 릴리스 버전 선택, 위조 링크 거부, 해시 오류 탐지, 파일 백업, 설치 성공, 쓰기 실패 시 네 파일 복원, 플랫폼별 공식 설치 파일 선택.
- 기존 동기화/복구/메모 방 통합/날짜별 정렬 테스트 및 가상 PC·모바일 화면 Chromium 테스트를 모두 통과한 빌드만 테스트 릴리스에 게시합니다.
