# 모두톡 Windows 17.5.6 · 이름 복구·상태 표시·파일 절약

- 복원 대기 방을 사용자가 다른 이름으로 바꾸면 같은 방 ID로 정식 공유방을 복구합니다. 임시 방 표시 때문에 이름 변경이 전송에서 빠지는 문제를 고칩니다. 손대지 않은 복원 대기 방과 충돌 보관함은 자동 복구하지 않습니다. 기존 메모·사진·댓글·수정 기록은 유지합니다.
- Windows의 파일 저장 옆 상태를 평소에는 ‘공유 폴더 연결됨’으로 유지합니다. 오류·권한 문제는 계속 표시하며 상세 단계는 공유 오류 진단과 마우스 도움말에서 봅니다. 연결 표시는 다른 기기로의 원격 전송 완료를 보장하지 않습니다.
- 읽기용 파일은 기본적으로 `memotalk-peer-v1/readable/current.md` 하나를 갱신합니다. 변경마다 만들던 Markdown의 계속된 증가를 줄입니다. 공유 확인·반영 간격 조절에서 이전 방식의 변경별 파일 생성을 다시 켜거나 기본값으로 돌아갈 수 있습니다.
- 동기화 원본 JSON은 그대로 유지합니다. 기존 읽기용 파일을 자동 삭제하지 않습니다. 이미 쌓인 파일은 별도 원본 보관 및 검증한 ZIP 보관을 거쳐 정리해야 합니다.

기존 앱을 정상 종료한 뒤 설치 파일로 업데이트하세요. 앱 제거·메모 초기화·공유 폴더 재연결은 필요 없습니다. Android 독립 앱은 기존 17.5.0이며, 휴대폰 Obsidian 연동 화면에는 별도 17.5.6 플러그인 업데이트가 제공됩니다.

단위 검사 62개, 실제 Windows 실행 파일의 메뉴·버전·재실행 보존 검사와 가상 두 기기의 편집·사진·충돌·초안·백업 보존 검사를 통과한 뒤 공개합니다. 연결되지 않은 실제 휴대폰의 최종 수신 확인은 별도로 필요합니다.
