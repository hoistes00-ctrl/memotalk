# 모두톡 연동 화면 17.5.4

- 방의 메뉴 → **메모방·백업에서 합치기**에서 현재 방 또는 **파일 저장의 백업·복원에 저장된 백업**을 선택할 수 있습니다. 백업 안의 방을 고르면 차이가 자동으로 비교됩니다. **필요한 메모 합치기**와 마지막 확인을 선택해야 실제로 반영됩니다.
- 백업 목록의 **메모방에 합치기**에서도 같은 기능을 엽니다. 전체 복원과 구분합니다. 기존 방·백업·메모는 보존하고 새 메모만 추가합니다. 댓글·사진·작성일을 유지하고 반복 통합의 중복을 방지합니다. 통합용 안전 백업 생성 시 기존 백업을 정리하지 않습니다.
- 목록의 폴더에 이름 변경 버튼을 바로 표시합니다. 폴더 메뉴의 **폴더 이름 바꾸기**에서도 변경할 수 있습니다. 앱 안의 폴더 이름만 바꾸며 연결된 실제 공유 폴더 경로는 유지합니다.
- 진단 제목이 실제 플러그인 버전을 표시합니다. Windows·Android 독립 앱은 기존 17.5.0 설치 버전을 유지합니다.
- 업데이트의 이전 파일을 고유한 폴더에 보관하고 백업과 복원을 해시로 확인합니다. 복원 실패를 성공처럼 안내하지 않습니다. 작성 중인 글·사진과 미전송 기록이 있으면 먼저 저장하도록 안내합니다. 같은 업데이트를 적용 전 반복 다운로드하지 않습니다.
- Obsidian의 모두톡 플러그인 설정에서 자동 업데이트 확인 간격과 안내 표시 시간을 조절·초기화할 수 있습니다. 안내 시간은 현재 표시 중인 안내에도 적용되고 조절값은 기기에 저장됩니다.

이번 파일은 Obsidian 연동 플러그인 업데이트입니다. 기존 업데이트 기능이 있는 17.5.3에서는 화면 위 **업데이트 → 업그레이드**로 설치한 뒤 플러그인을 껐다 켭니다. 그 이전 버전은 ZIP 안의 네 코드 파일을 기존 플러그인에 적용합니다. 기존 `data.json`, 메모 저장소와 공유 그룹을 초기화하지 마세요.

자동 검사와 PC·휴대폰 크기 가상 화면의 버튼 조작·동기화 검사를 통과한 후 공개하는 시험판입니다. 최초 공개 시점에는 실기기 자기 업데이트와 실제 파일 왕복 검증이 진행 중입니다. 확인된 실기기 결과는 후속 기록으로 구분해 남깁니다. 화면 꺼짐·앱 종료 동안의 즉시 전송을 보장하지 않습니다.
