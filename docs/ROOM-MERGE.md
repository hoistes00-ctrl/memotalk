# 같은 공유 방 자동 통합

모두톡 17.3.0은 같은 공유 그룹에 들어온 방 복사본을 PC·Android 공통 엔진에서 통합합니다. 원래 operations JSON과 readable Markdown 파일은 덮어쓰거나 삭제하지 않습니다.

## 같은 방을 알아보는 기준

- 일반 채팅방의 제목(유니코드·공백 정리 및 예전 `(불러옴)` 접미사 처리), 정확한 방 생성 시각, 공통 메모 작성 시각이 함께 일치해야 자동 통합합니다. 메모 본문은 서로 편집되어 달라도 됩니다.
- 제목만 같거나 생성 시각을 모르는 방, 공통 메모 작성 시각이 없는 방, 빈 방은 자동 통합하지 않습니다. 시스템 충돌 보관함과 폴더도 대상이 아닙니다. 날짜가 대략 비슷하다는 이유로 합치지 않습니다.
- 이미 합친 방의 관계는 공유 변경 이력에 저장합니다. 합쳐지기 전 방 번호로 늦게 도착한 메모도 통합된 방 안으로 옮겨집니다.

## 메모를 보존하는 방법

- 작성 시각·본문·첨부 내용이 같은 메모 복사본은 하나로 표시합니다. 사진 표시 크기 차이는 중복 판정을 방해하지 않습니다.
- 한쪽에만 있는 메모는 추가합니다. 본문이나 사진이 다르면 다른 버전도 같은 방 안에 남깁니다. 가장 최근 날짜 하나로 덮어쓰거나 문장 일부를 추측하여 고치지 않습니다.
- 댓글도 작성 시각·내용을 비교해 합칩니다. 한 원본 방 안에 의도적으로 반복 작성한 같은 메모·댓글 개수는 유지합니다.
- 메모의 원래 방·메모 번호를 기록합니다. 통합은 새 변경 이력으로 게시하므로 이전 원본은 이력에서 보존됩니다. 전송이 끊기면 저장된 발신 대기 이력을 다시 보냅니다.
- 병합을 만드는 기기와 결과를 받는 기기 모두 로컬 안전 백업을 먼저 만듭니다. 백업에 실패하면 그 기기의 병합 반영을 중단합니다. 병합과 동시에 입력된 새 메모는 저장 토큰을 재확인하여 다음 주기에 함께 반영합니다.
- 열어 두었던 복사본 방이 합쳐지면 통합 방으로 이동합니다. 입력 중 문장과 첨부 대기 사진을 유지하며, 예전 방 번호로 연 별도 창도 통합 방으로 연결합니다.

## 확인 범위

합성 자료로 반복 가져오기, 순서 독립성, 오프라인 양쪽 통합, 늦은 메모, 원본 이력 보존, 중간 전송 중단, 반영 중 새 편집, 백업 실패를 검사합니다. 실제 앱 화면의 두 프로필 시험은 백업 가져오기와 댓글·사진·다른 편집본·입력 중 내용의 보존을 확인합니다. Android SAF/WebView와 설치된 Windows 앱의 왕복 시험에도 서로 다른 번호의 같은 방을 포함합니다. 실제 휴대폰에 이 버전을 설치해 시험했는지는 별도 배포 기록에서 구분해야 합니다.

방 생성 시각이 다르거나 빠진 옛 복사본은 자동 통합하지 않을 수 있습니다. 제목만으로 무리하게 합쳐 다른 방의 내용을 섞지 않기 위한 기준입니다. 서로 겹친 편집 문장의 의미를 판단하는 자동 문장 재작성은 하지 않습니다.
