# 제목과 현재 위치 — 모두톡 17.4.0

## PC 목록 제목

방과 폴더의 제목을 기본적으로 끝까지 줄바꿈하여 표시합니다. 제목과 라벨·날짜·미리보기를 다른 줄로 분리하고, 격자에서는 제목이 길면 칸도 함께 커집니다. 글자 수를 잘라서 제목 데이터를 바꾸지 않습니다. 한국어 단어는 가능한 한 통째로 다음 줄로 넘기고, 공백 없는 긴 문자열도 칸 밖으로 넘치지 않게 표시합니다.

조작 설정에서 다음 대안을 즉시 선택할 수 있으며 다음 실행에도 유지됩니다. 각 항목에 기본값 복귀 버튼이 있습니다.

| 표시 | 용도 |
| --- | --- |
| 전체 표시 (기본) | 제목을 전부 읽는 것이 중요할 때 |
| 두 줄 요약 | 더 많은 방을 한 화면에서 볼 때 |
| 한 줄 요약 | 가장 조밀한 목록이 필요할 때 |

요약 모드에서도 마우스를 올리면 원래 제목을 볼 수 있고, 열린 방 상단은 전체 제목을 표시합니다. 제목 글자 크기와 줄 간격도 숫자로 조절할 수 있습니다. CSS가 허용하는 0 이상의 유한한 값을 입력하며 0은 제목을 숨기거나 줄을 겹치게 할 수 있으므로 기본값 복귀 버튼으로 되돌릴 수 있습니다. 이 설정은 해당 기기의 표시만 바꾸며 공유 메모·제목·폴더를 수정하지 않습니다.

## 두 종류의 위치

- 열린 방 상단의 `전체 / 폴더 / 하위 폴더 · 위치 보기`를 누르면 앱 안의 위치와 실제 저장 폴더를 구분해 볼 수 있습니다.
- 방을 열지 않았을 때도 `파일 저장 → 현재 폴더·저장 위치 보기`에서 실제 저장 폴더를 확인합니다.
- 앱 안의 경로는 분류 위치입니다. 이 경로가 같은 이름의 실제 디스크 폴더로 자동 만들어졌다고 뜻하지 않습니다.
- 실제 저장 위치는 현재 이 기기에서 선택한 파일 폴더입니다. PC는 전체 경로를 표시하고 복사하거나 탐색기로 열 수 있습니다. 탐색기로 여는 기능은 이미 선택한 폴더만 사용하며 임의 경로를 받지 않습니다.
- Android는 시스템이 제공한 문서 폴더 경로와 저장소 구분이 들어 있는 원래 문서 경로를 표시합니다. 이를 추측한 `/storage/...` 절대 경로로 바꾸지 않습니다.
- 일반 브라우저가 폴더 이름만 제공하는 경우 전체 경로라고 표시하지 않습니다. 실제 폴더 연결이 없으면 연결되지 않았다고 안내하며, 메모가 없다는 뜻으로 표시하지 않습니다.

`목록에서 찾기`는 검색·라벨 필터를 풀고 상위 폴더를 펼쳐 현재 방의 위치로 이동합니다. 입력 중 문장은 유지합니다. 폴더가 아직 내려오지 않았거나 구조에 문제가 있으면 이를 표시하며 올바른 경로처럼 꾸미지 않습니다.

## 검증 범위

합성 자료로 PC·Android 크기의 목록과 격자, 긴 한글 제목·공백 없는 제목, 전체 경로·Android 문서 경로, 폴더 펼치기와 현재 방 찾기, 작성 중 입력 유지, 글자 크기·줄 간격·요약 설정의 즉시 반영·재실행·기본값 복귀를 시험합니다. 표시·위치 기능 사용 전후 메모 데이터가 같은지 비교합니다. 네이티브 경로 표시는 실제 설치된 Windows 앱과 Android SAF 실행 시험에서도 확인합니다. 실제 휴대폰에서 이번 화면을 확인했는지는 별도 배포 기록에서 구분합니다.
